# Repository Information:

This is a github repository which contains all the files needed a report that analyses shooting trends in the NBA to gauge wether an increase in 3pt shots has led to grreater scoring.
This report contains 3 folders and 6 files and below are descriptions on what each of them do. 

.CircleCi: This is a folder containing all files necessary for the CICD of this project including the config.yml

Figures: This is a folder containing all the figures which is generated by running the Project.py file

_pycache: This is a folder that contains bytecode cache files that are automatically generated by python

NBA_03: CSV file with data needed to run the code

NBA_13: CSV file with data needed to run the code

NBA_23: CSV file with data needed to run the code

Project.py: File which has all the code needed to generate the figures

Unit_Test.py: File with all the unit tests needed for the code

requirements.txt: text file with all the requirements that are needed to run the code
